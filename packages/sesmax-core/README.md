# sesmax-core

The core of [sesmax](https://github.com/jejjohnson/sesmax): the state and parameter types, term algebra, steppers, forcing, data-assimilation adapters and I/O that every simple Earth-system model in the workspace shares.

The package is empty until phase C1 of the [workspace and core design](../../docs/design/workspace_and_core.md), which moves this machinery from somax.
